Move your tracker between phone & laptop

Your saved/applied jobs live in this browser. Copy them across with a file, or turn on free auto-sync below.

Auto-sync (free, via a private GitHub Gist)

  1. On GitHub: Settings → Developer settings → Personal access tokens → Fine-grained → Generate.
  2. Account permissions → Gists: Read and write. Nothing else.
  3. Paste the token here on each device. The first device creates the gist; copy its Gist ID to the other device.

The token is stored only in this browser and only sent to api.github.com.
